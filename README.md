# Heart Disease Prediction using Decision Trees & Random Forests

This project involves implementing **Decision Tree** and **Random Forest** models to classify heart disease using a dataset of patient health records. The goal is to understand tree-based machine learning models and evaluate their performance using visualization and cross-validation.

---

## Dataset

- **Source:** [Heart Disease Dataset – Kaggle](https://www.kaggle.com/datasets/johnsmith88/heart-disease-dataset)
- The dataset contains patient information like age, cholesterol, chest pain type, etc., along with a target column indicating presence (`1`) or absence (`0`) of heart disease.

---

## Objectives

- Train and visualize a Decision Tree Classifier
- Analyze overfitting and control tree depth
- Train a Random Forest Classifier and compare performance
- Evaluate model using cross-validation
- Interpret and visualize feature importances

---

## Tools and Libraries Used

- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn
